Alur Utama (Skenario Normal)

Admin memilih menu dan data mahasiswa yang akan dihapus.   
image_3dfea0.png

Sistem memeriksa ketersediaan data dan memastikan tidak ada data akademik aktif.   
image_3dfea0.png
+ 1

Setelah Admin mengonfirmasi penghapusan, sistem menghapus data dari basis data dan menampilkan pesan berhasil.   
image_3dfea0.png

Alur Alternatif (Error Handling)

Data Tidak Ditemukan: Sistem menampilkan pesan bahwa data mahasiswa tidak tersedia, lalu alur berakhir.   
image_3dfea0.png

Data Akademik Masih Aktif: Sistem menolak penghapusan dan menampilkan pesan bahwa mahasiswa masih memiliki data aktif, lalu alur berakhir.   
image_3dfea0.png

Batal Konfirmasi: Admin membatalkan konfirmasi, sehingga sistem membatalkan proses tanpa mengubah isi basis data.
